사용 설명서
기본 사용 순서
  1. Photoshop에서 처리할 문서를 엽니다.
  2. 기본값인 현재 레이어를 확인하거나 다른 처리 범위를 선택합니다.
  3. 필요하면 세부 설정에서 결과 레이어와 옵션을 조정합니다.
  4. StarNet2 실행을 누르고 완료될 때까지 기다립니다.
처리 범위
보이는 레이어
현재 보이는 모든 레이어를 합성해 처리합니다.
현재 레이어
선택한 일반 픽셀 레이어만 처리합니다.
지정 영역
선택 영역 또는 현재 레이어 마스크를 모든 결과 레이어에 적용합니다.
결과 레이어

Stars

Star Boost (Large)
Stars에서 큰 별만 선별한 강조 레이어입니다.
처리 옵션

큰 별 강조 강도는 Star Boost (Large)의 불투명도를 조절합니다.
